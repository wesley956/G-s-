# Direção visual — V1

## Objetivo
O sistema deve parecer um programa comercial moderno, rápido e confiável, sem excesso de elementos e sem aparência de site/cardápio.

## Identidade
- Base: grafite escuro
- Superfícies: azul-grafite
- Cor de ação: azul forte
- Sucesso/online: verde
- Atenção/estoque baixo: âmbar
- Erro/cancelamento: vermelho
- Texto principal: branco suave
- Texto secundário: cinza azulado

## Estrutura
- Menu lateral fixo
- Área principal ampla
- Títulos grandes e claros
- Cards apenas para indicadores
- Tabelas para operação diária
- Formulários divididos em blocos curtos
- Botões principais sempre visíveis e consistentes

## Diretrizes de UX
- Operador deve concluir uma venda com poucos cliques
- Portaria e Entrega precisam ficar visualmente evidentes
- Valores monetários devem ter alto contraste
- Estoque baixo nunca deve depender somente de cor; usar ícone + texto
- Ações destrutivas precisam de confirmação
- Interface otimizada primeiro para monitor/PC Windows

## Componentes-chave
- Menu lateral com módulos
- Cabeçalho de página
- Cards de indicadores
- Tabela operacional
- Campo de busca destacado
- Status pills
- Formulário com seções
- Botões Primário/Secundário/Fantasma

## Impressão
O visual da tela é escuro, mas comprovantes impressos serão em layout claro/preto-e-branco, otimizado para impressora térmica.
